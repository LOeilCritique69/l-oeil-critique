Comment fonctionne ce calendrier et à quoi sert-il ?

Un agenda éditorial centralisé. Cette page rassemble les dates suivies par L’Œil Critique. Les sorties sont enregistrées dans le tableur de gestion, puis transmises à cette page par une API Google Apps Script. Le HTML ne contient pas la liste des sorties en dur.

Comment l’utiliser ? Parcourez les mois avec les flèches, sélectionnez une catégorie, recherchez un titre ou ouvrez une journée pour consulter les détails. La fenêtre d’une sortie peut proposer une affiche, un lien d’information et un ajout à Google Calendar.

Votre calendrier, vos règles. Les filtres par catégorie, plateforme et période permettent de réduire la liste. Les préférences sont conservées dans un cookie fonctionnel sur cet appareil ; elles ne nécessitent pas de compte.

Dates françaises. Pour les films, la page tente de récupérer une date française explicitement enregistrée dans TMDB. Si aucune date française fiable n’est disponible, la date du tableur est conservée. Les séries, jeux, animés et événements utilisent la date fournie par le calendrier éditorial.

Important pour la saisie : le tableur attend des dates au format français JJ/MM/AAAA (ex. 16/12/2026), ou MM/AAAA lorsque le jour est inconnu. Une date américaine ambiguë déjà enregistrée dans le tableur ne peut pas être devinée avec certitude par le navigateur : elle doit être corrigée dans la source. Ce produit utilise l’API TMDB sans être approuvé ni certifié par TMDB.
